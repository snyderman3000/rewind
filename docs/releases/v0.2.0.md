**Rewind 0.2.0** can send movies to Radarr.

### New
- **Add to Radarr:** press **X** on a movie's details or trailer screen. Rewind shows the quality profile, folder and free space, then adds the movie to Radarr and starts a search. Once Radarr downloads it, it lands in Plex (or anything else watching that folder).
- **What you already have:** the shelf marks movies in Radarr (● downloaded, ○ still coming), and the details screen shows download progress and time left.
- **New filter, My library:** show everything, hide what you already have, or show only what you have.

### Setup
Add these to `App/Rewind/data/config.json` (see `config.example.json`):
```json
"radarr_url": "http://192.168.1.20:7878",
"radarr_api_key": "from Radarr → Settings → General",
"radarr_quality_profile": "HD-1080p",
"radarr_root_folder": "/movies"
```
The last two are optional; without them Rewind uses Radarr's first profile and folder. The handheld has to be on the same network as Radarr.
